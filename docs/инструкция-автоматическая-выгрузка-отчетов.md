# Инструкция по настройке автоматической выгрузки отчетов (Пункт 9)

## Описание

Система автоматически генерирует и сохраняет отчеты:
- **Квартальные отчеты** - за каждый квартал (Q1, Q2, Q3, Q4)
- **Полугодовые отчеты** - за каждое полугодие (H1, H2)

## Установка

1. **Установка агентов** (выполнить один раз):
   - Открыть в браузере: `http://ваш-сайт/tx_files/install_auto_export_agents.php`
   - Требуются права администратора
   - Агенты будут установлены в систему Bitrix

2. **Проверка установки**:
   - Перейти в админ-панель: `Настройки` → `Настройки продукта` → `Агенты`
   - Должны быть видны два агента:
     - `TenderixAutoExportQuarterly()`
     - `TenderixAutoExportHalfYearly()`

## Расписание работы

- **Квартальные отчеты**: генерируются каждый день в 02:00 (за предыдущий квартал)
- **Полугодовые отчеты**: генерируются каждый день в 02:30 (за предыдущее полугодие)

## Расположение файлов

- **Отчеты сохраняются в**: `/upload/tenderix_reports/`
- **Лог генерации**: `/upload/tenderix_reports/export_log.txt`
- **Формат файлов**: Excel (.xls)

## Формат имен файлов

- Квартальные: `report_quarter_Q1_2025.xls`, `report_quarter_Q2_2025.xls`, и т.д.
- Полугодовые: `report_halfyear_H1_2025.xls`, `report_halfyear_H2_2025.xls`

## Структура отчета

Каждый отчет содержит:
- ID лота
- Название лота
- Дата завершения
- Количество предложений
- Победитель тендера

## Ручная генерация отчетов

Для ручной генерации отчета можно использовать URL:

**Квартальный отчет:**
```
http://ваш-сайт/tx_files/reports_auto_export.php?action=generate_quarter&year=2025&quarter=1
```

**Полугодовой отчет:**
```
http://ваш-сайт/tx_files/reports_auto_export.php?action=generate_halfyear&year=2025&halfyear=1
```

## Настройка расписания

Для изменения времени запуска агентов:
1. Перейти в админ-панель → `Агенты`
2. Найти нужный агент
3. Изменить параметр `Следующий запуск` или `Интервал`

## Примечания

- Отчеты генерируются только для завершенных тендеров
- Если за период нет завершенных тендеров, отчет не создается
- Агенты работают автоматически при каждом обращении к сайту (через `CAgent::CheckAgents()`)
- Для более точного расписания рекомендуется настроить cron-задачу для вызова `/bitrix/admin/agent.php`

## Устранение неполадок

1. **Агенты не запускаются**:
   - Проверить, что агенты активны в админ-панели
   - Убедиться, что есть обращения к сайту (агенты запускаются при каждом обращении)
   - Проверить права на запись в `/upload/tenderix_reports/`

2. **Отчеты не генерируются**:
   - Проверить лог: `/upload/tenderix_reports/export_log.txt`
   - Убедиться, что есть завершенные тендеры за указанный период
   - Проверить права на запись файлов

3. **Ошибки в логах**:
   - Проверить, что модуль `pweb.tenderix` установлен и активен
   - Проверить корректность путей к файлам
