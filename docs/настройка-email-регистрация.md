# Настройка email-уведомлений при регистрации участников (Пункт 2)

## Описание

После успешной регистрации участника на электронной торговой площадке Tenderix.kz автоматически отправляется email-уведомление на указанный при регистрации адрес электронной почты.

## Что было реализовано

В компоненте регистрации поставщиков (`supplier.reg`) добавлена автоматическая отправка email-уведомления при успешной регистрации нового участника.

## Настройка почтового шаблона в Bitrix

Для работы уведомлений необходимо создать почтовый шаблон события в админ-панели Bitrix:

1. **Перейти в админ-панель**: `Настройки` → `Настройки продукта` → `Почтовые события`

2. **Создать новое почтовое событие**:
   - Код события: `TENDERIX_SUPPLIER_REGISTERED`
   - Название: "Регистрация поставщика на Tenderix"

3. **Создать почтовый шаблон** для этого события:
   - Перейти в `Почтовые шаблоны`
   - Нажать "Добавить шаблон"
   - Выбрать событие: `TENDERIX_SUPPLIER_REGISTERED`
   - Заполнить поля:
     - **Тема письма**: `Добро пожаловать на Tenderix.kz!`
     - **Тип**: HTML
     - **Сообщение** (пример):

## Доступные переменные в шаблоне

В почтовом шаблоне можно использовать следующие переменные:

- `#EMAIL_TO#` - Email адрес получателя
- `#EMAIL_FROM#` - Email адрес отправителя
- `#LOGIN#` - Логин пользователя
- `#NAME#` - Имя пользователя
- `#LAST_NAME#` - Фамилия пользователя
- `#SECOND_NAME#` - Отчество пользователя
- `#FIO#` - Полное ФИО (Фамилия Имя Отчество)
- `#NAME_COMPANY#` - Название компании (если указано)
- `#SITE_NAME#` - Название сайта
- `#SITE_URL#` - URL сайта

## Проверка работы

1. **Зарегистрировать нового участника** через форму регистрации
2. **Проверить почтовый ящик** указанный при регистрации
3. **Проверить логи** отправки писем в Bitrix (если включено логирование)

## Настройка SMTP (если требуется)

Если письма не отправляются, проверьте настройки SMTP в Bitrix:

1. `Настройки` → `Настройки продукта` → `Настройки модулей` → `Почта`
2. Настроить SMTP-сервер для отправки писем
3. Проверить настройки в `Настройки` → `Настройки продукта` → `Настройки модулей` → `Главный модуль` → `Почта`

## Примечания

- Уведомление отправляется только при **первой регистрации** участника (не при обновлении данных)
- Письмо отправляется на email, указанный при регистрации
- Если email не указан или указан некорректно, письмо не будет отправлено
- Для работы требуется корректная настройка почтового сервера в Bitrix

## Устранение неполадок

1. **Письма не приходят**:
   - Проверить настройки SMTP в Bitrix
   - Проверить, что почтовый шаблон создан и активен
   - Проверить логи ошибок Bitrix
   - Убедиться, что email указан корректно

2. **Письма приходят, но без форматирования**:
   - Проверить, что тип шаблона установлен как "HTML"
   - Проверить корректность HTML-разметки в шаблоне

3. **Переменные не подставляются**:
   - Убедиться, что используются правильные названия переменных (с #)
   - Проверить, что переменные указаны в списке доступных для события
